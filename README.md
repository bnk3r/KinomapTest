# KinomapTest

-> Android App Directory : KinomapTestAndroid
-> Features :
  - 100% Kotlin + Jetpack Compose
  - Features MDP (Model - Domain - Presentation) architecture 
  - Fetch data using Retrofit (REST API - Json data)
  - Dependency Injection using Koin
  - Image Loading using Coil
  - Navigation using AndroidX Navigation
  - Category list screen + Badge details screen
  - Particles effect (Canvas) to enhance badge completion
  - Personal app icon using Figma
  - Landscape layouts for both screens
  - FAB to scroll to start of categories
  - Internet status handling (info display when missing, fetching on re-connection)
  - Filters on categories (badge's lock and completion state)
